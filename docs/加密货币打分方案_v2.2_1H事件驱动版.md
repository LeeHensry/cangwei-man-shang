# 加密货币打分方案 v2.2 —— 1H 事件驱动版（定稿）

> 演进路径: v1 规则加分制 → v2.0 事件驱动(日线) → v2.1 多空分离+网格优化(日线/1H) → **v2.2 三币 1H 定稿**
> 数据基座: BTC/ETH/SOL 全量 K 线（1d/4h/1h，2019-06 起，币安官方镜像 data-api.binance.vision）
> 回测引擎: `scripts/crypto_backtest_1h.py`（逐 1H 评估、下一根开盘入场、逐小时检查触价、保守先止损口径）
> 定稿依据: 96 组参数网格（三币专属）+ 8 币池交叉验证 + 分年/分币稳定性检查

---

## 一、v2.2 最终配置（LONG 策略，唯一实跑策略）

### 1.1 信号定义（逐 1H K 线评估）

```
环境门控（用上一已完成 UTC 日的日线数据, 无未来函数）
  G1: BTC close > SMA20 × 1.03          （BTC 强势区）
  G2: BTC SMA20 上行（SMA20 > 5日前SMA20）

背景条件（用上一已完成 UTC 日, 三条全要）
  B1: 日线多头排列 SMA5 > SMA20 > SMA60
  B2: 日线 MACD dif > dea
  B3: 4H SMA5 > SMA20（取最近一根已完结的4H K线）

事件触发（当日每小时检查, 命中即发信号）
  E1 强事件: 量比 > 2.0 且 24h滚动涨幅 > 3% 且 close > 前20个已完成UTC日最高价
  E2 次事件: 量比 > 2.0 且 24h滚动涨幅 > 3%
  量比 = 当前1H成交量 ÷ 同小时(时:分)过去14天均值   ← 消除日内季节性

冷却: 同币发信号后 24 小时内不再发
```

### 1.2 交易与风控

| 参数 | 值 | 说明 |
|---|---|---|
| 入场 | 信号 K 线的下一根 1H 开盘价 | 信号在 K 线收盘时刻判定 |
| 止损 | 入场价 − 2×ATR14（钳制 2%~15%） | ATR 用上一完成日的日线 ATR14 |
| 止盈 | 入场价 + 2×ATR14（盈亏比 1:1） | 与止损对称 |
| 最大持仓 | 7 天（168 根 1H）到期市价平仓 | 回测到期占 28% |
| 触价检查 | 逐 1H high/low，同根双触保守算先止损 | |
| 手续费 | 单边 0.1%（taker 口径） | |
| 仓位 | 风险预算 3% 净值/单 → 名义敞口 = 3% ÷ 止损距离%，封顶 100%（=5x×20%保证金） | 波动大敞口自动收缩 |

### 1.3 SHORT 策略（独立模块，只记录不下单）

多空分离后做空单独成模块。192 组做空配置全网格搜索结论：**无可用边际**——最优配置（24h涨>12% + 放量 + RSI>75）胜率 59.4% 但单均期望 ≈0（+0.024%），7 年净值 0.99x。处置：影子运行攒证据，每月复诊，连续两季度期望转正再讨论上线。

## 二、回测证据链

### 2.1 关键迭代结论（为什么是现在这个配置）

| 迭代 | 结论 | 证据 |
|---|---|---|
| v1 固定风控是灾难 | 5% 固定止损被噪音秒杀 | 3198单/胜率33.8%/净值 0.00x（归零） |
| ATR 自适应风控救活 | 同信号净值 0.00x → 3.20x | B组 vs A组 |
| 门控必要 | BTC<SMA20 期做多 = 比闭眼买差 -2.08pp/7d | 7年11673信号回放 |
| E3(单纯突破新高)是拖累 | 修复后仍最弱(+0.13%/单) | 事件拆解 |
| 分数越高越差 | score 80+ 胜率 49.9% < 72-75 的 56.2% | 共振追高效应 → 废除总分制 |
| **多空分离** | 做空无边际，独立模块后互不抢冷却 | 192组做空网格 |
| **1H 粒度** | 止损可收紧、信号频率翻倍、执行精度提升 | 1H vs 日线对照 |

### 2.2 三币 1H 网格（96 组，n≥80 大样本 66 组）

| 配置 | n | 胜率 | 单均 | 净值 | 回撤 | 均持 |
|---|---|---|---|---|---|---|
| **定稿: E1E2 vr2.0 pct3 cd24h SL2.0 RR1.0** | **132** | **63.6%** | **+0.746%** | **2.56x** | **-9.3%** | 98h |
| 备选(高胜率): 同参数 SL1.5 RR0.75 cd48h | 105 | 67.6% | +0.605% | 1.84x | -15.8% | 61h |

定稿理由：胜率 63.6% 已达 60% 目标；期望（+0.75%）、净值（2.56x）、回撤（-9.3%）、样本量（n=132）四项全面占优；且 SL 2×ATR 更符合用户"止损更松"的偏好。备选适合只想要最高胜率的场景。

## 三、诚实前提（必读）

1. **样本量有限**：三币 7 年 132 单，年均 ~19 单；分年胜率置信区间宽，60%+ 是全周期数字；
2. **2026 年胜率不过半**（45%）：近年市场效率上升是持续趋势，当前靠盈亏比 1:1 下"赢的单更大"维持正期望；若模拟盘 3 个月期望转负应触发复诊；
3. **网格搜索有幸存者偏差**：96 组选 1，已用 H1/H2 稳定性（71.2/64.2 均高）+ 8 币交叉验证 + 分年检查对冲，但最终裁判是模拟盘；
4. **幸存者偏差**：历史回测的币种都是活到今天的；真实交易环境（滑点、资金费率、流动性）比回测恶劣；
5. **模拟盘与实盘的差距**：模拟盘按 1H 收盘判定+下一根开盘成交，实盘会有滑点；手续费按 taker 0.1% 已偏保守。

## 四、模拟盘实测设计

| 项 | 设计 |
|---|---|
| 标的 | BTC/ETH/SOL（只做多） |
| 初始资金 | 虚拟 10,000 USDT |
| 运行节奏 | **每小时运行一次**（1H K 线收盘后判定信号 + 检查持仓触价/到期） |
| 持仓状态 | 本地 JSON（`data/crypto/paper/state.json`）：余额、持仓、成交流水 |
| 信号记录 | 全部信号（含未开仓的）落 CSV，用于事后胜率核对 |
| 影子池 | 8 币池影子信号（只记录不下单）+ SHORT 策略影子 |
| 报表 | 每日日报：净值曲线、持仓、已平仓盈亏、累计胜率 |
| 对标基准 | 三币等权买入持有（同起点 1 万 USDT） |
| 周期 | 建议 6-8 周；期间不改参数 |
| 复诊触发 | 连续 20 单胜率 <50% 或净值回撤 >15% → 停下复盘 |
