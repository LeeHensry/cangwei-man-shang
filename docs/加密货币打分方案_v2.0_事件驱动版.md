## 三、v2 方案定稿

### 3.1 信号架构：环境门控 + 事件驱动

```
市场环境层（分级门控，2026-09-10 用户确认放宽）
  r = BTC日线close / SMA20
  r >= 0.97          → 正常区: LONG 事件正常触发
  r < 0.97（深熊）    → 限制区: 仅 E1（放量突破）可触发 LONG，
                        且仓位减半；S2/S3 类弱事件全部不触发
  注: 硬门控(r>=1)与分级门控(r>=0.97)两版均进回测对照，用数据定稿

信号层（事件触发，非分数触发）
  LONG 事件:
    E1 放量突破: 量比>2 且当日涨幅>3% 且 close>20日高        → 强信号
    E2 放量上涨: 量比>2 且当日涨幅>3%                        → 强信号
    E3 突破新高: close>20日高 且当日涨幅>2%                  → 强信号
    背景条件（需至少满足1条，否则事件作废）:
      日线 SMA5>SMA20>SMA60 / MACD dif>dea / 4H SMA5>SMA20

  SHORT 事件（不受牛熊门控限制）:
    S1 过热反转: 24h涨幅>10%（等效日线单日涨幅>10%）
       加强条件（二选一）: RSI14>75 或 close>BOLL上轨
```

### 3.2 与 v1 的结构差异

| 维度 | v1（现行） | v2（本方案） |
|---|---|---|
| 信号判定 | 加分制总分过阈值（≥72 / ≤28） | 事件直接触发，无总分 |
| 环境感知 | 无 | BTC SMA20 门控 LONG |
| 做空规则 | 5 条（4 条实测无效） | 仅保留过热反转 1 条 |
| watch 层 | watch_long / watch_short（7,798 个噪声） | 删除，只留"强事件信号" |
| 趋势指标角色 | 直接加分（三重计数） | 只作背景条件（或否决票） |
| 止损止盈 | 固定 5% / 12% | ATR 自适应（见 3.3） |
| 仓位 | 固定杠杆 3x / 2x | 单币单仓，风险预算制（见 3.4） |
| 展示分 0-100 | 有 | 保留展示（按事件强度+背景条件数生成），但不参与信号判定 |

### 3.3 风控参数（ATR 自适应，2026-09-10 用户确认放宽）

| 参数 | 公式 | 说明 |
|---|---|---|
| 止损 | 入场价 ± 2×ATR14 | 多单在下、空单在上；替代固定 5% |
| 止盈 | 入场价 ± 4×ATR14 | 盈亏比固定 2:1 |
| 最大持仓 | 14 天 | 到期未触价按市价平仓（模拟盘统计用） |
| 空单硬止损 | 止损必须执行，不可放宽 | 回测最差 -148% 的教训 |
| 手续费 | 单边 0.1% | 回测与模拟盘均计入 |

### 3.4 仓位管理（2026-09-10 用户确认杠杆上限 5x）

- **风险预算制**：单笔到止损位的亏损 = 账户净值的 3%（风险恒定，不随币种波动变化）
- 名义敞口 = 净值 × 3% ÷ (2×ATR%)，BTC（低波）敞口自动大、山寨（高波）自动小
- 杠杆上限 5x，即名义敞口封顶 = 净值 × 20% 保证金 × 5 = 100% 净值
- 单币同时最多 1 仓（BTC/ETH/SOL 互不占用，同一币不叠加）
- 信号冲突（同日多事件）取事件强度优先级：E1 > E2 ≈ E3 > S1
- 深熊限制区内触发的 E1 信号，名义敞口再减半

### 3.5 币种范围

- **模拟盘实测标的：BTC / ETH / SOL**（用户指定；流动性最好、无下架风险、波动率彼此有梯度）
- 线上页面仍展示全池 26 币的 v2 信号，仅模拟盘只执行三币

## 四、回测对照计划（下一步执行）

同一数据集（26 币 7 年日线）上对照两套规则：

| 对照项 | 内容 |
|---|---|
| 组A | v1 现行信号 + v1 固定风控（5%/12%止损止盈） |
| 组B | v1 现行信号 + ATR 风控（隔离风控改进的贡献） |
| 组C | v2 事件信号 + **硬门控**（BTC<SMA20 禁多）+ ATR 风控 |
| 组D | v2 事件信号 + **分级门控**（深熊仅E1可多、仓位减半）+ ATR 风控 ← 用户倾向 |
| 通过门槛 | ① 7d胜率(组D信号窗口) ≥ 55%；② 组D平均单笔超额 ≥ +3pp（vs 全池基线）；③ 组D最大单笔亏损 ≤ -8%；④ 组D模拟净值曲线最大回撤 ≤ 组A；⑤ 空单单笔最差 ≥ -8%（止损生效） |

产出：`scripts/crypto_backtest_v2.py` + 对照报告，达标后进入模拟盘。

## 五、模拟盘实测方案（回测达标后启动）

| 项 | 设计 |
|---|---|
| 标的 | BTC / ETH / SOL（USDT 计价） |
| 初始资金 | 虚拟 10,000 USDT |
| 信号时点 | 每日 16:00（北京时间，收盘数据齐全后） |
| 执行 | 信号触发 → 模拟市价开仓 → 同时记录止损/止盈价 → 之后每日收盘检查触价与到期 |
| 数据与状态 | 币安日线（data-api.binance.vision 镜像）；持仓/成交记录存本地 JSON（`data/crypto/paper/`） |
| 调度 | WorkBuddy 自动化每交易日 16:00 运行（与 A 股 15:30 管线错开） |
| 评估指标 | 信号数、胜率、累计收益、最大回撤、盈亏比、vs 三币等权买入持有基准的超额 |
| 时长 | 建议 6-8 周（预期 20-40 个信号） |
| 报告 | 每日简报（信号/持仓/净值），周度汇总 |
