# 加密货币策略 v2.5 定稿 — ETH 多空双向·5:5 风险配比

> 定稿时间: 2026-09-10 | 数据: ETH 7年 1H (63,757根) + BTC/ETH 日线 | 回测: 仓位感知模拟(并发上限诚实口径)

## 一、策略哲学

行情好坏 = 年内有无大波动率（上涨下跌都是机会），不局限于做多。多头抓牛市爆发窗口，空头填熊市/回调期的收益空窗——回测证明两者互补后 **7年无亏损年**。

## 二、定稿配置

### LONG 策略（风险预算 15%/单）
| 模块 | 配置 |
|---|---|
| 事件 | E1放量突破 / E2放量上涨 / E3突破新高 / E4回踩企稳 / E5波动收缩突破（量比>1.5同小时基线 + 24h滚动涨幅>1.5%） |
| 门控 | 软门控: BTC日线收盘 > SMA20×1.03 |
| 背景 | 三条件全要: ETH日线多头排列 + MACD多头 + 4H SMA5>SMA20 |
| 风控 | SL=1.5×ATR(钳制2%-15%) / TP=1:1 / 到期168h平仓 / 冷却6h |

### SHORT 策略（风险预算 6.5%/单）
| 模块 | 配置 |
|---|---|
| 事件 | mirror趋势跟空: 放量下跌(量比>2.0 + 24h跌幅>2.0%) 或 破20日低 |
| 门控 | 熊市三重确认: ETH日线空头排列 + MACD死叉 + BTC < SMA20 |
| 风控 | SL=1.5×ATR / TP=1:1 / 到期168h / 冷却6h |

### 组合层
- **风险配比 5:5**（实际总风险敞口口径：long 15% × 频次 ≈ short 6.5% × 频次）
- 多空共用并发池上限 4 仓；名义敞口 = min(风险/止损距离, 2.4)
- **熔断**: 连续3笔止损 → 暂停开仓168h（回测证明单调改善：年化4.96→5.93x、回撤-77.5→-63.7%）

## 四、诚实预期（必须读）

1. **不等年份的数学平均**: 中位年份 2-3x，出现 2024-02/11 型爆发窗口的年份 5-19x；
2. 收益 TOP2 月份贡献全年 ~70% 利润（趋势爆发窗口收割机的固有性格）；
3. 熔断版已把弱年从放血转为正贡献（2025年3.01x/2026年1.49x 纯多头口径，加空头后 3.67/2.69）；
4. 回测止损按精确价成交，8x级别杠杆下真实滑点会吃掉部分收益，**模拟盘数字预期比回测打对折**。
