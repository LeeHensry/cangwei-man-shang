## 关键教训
- AntD Sider的collapsible默认有trigger（48px底部按钮），会和自定义底栏重叠→需要trigger={null}禁用
- Sider用内部wrapper div包裹，直接在Sider上设flex无效→需要内部包一个flex column的div
- 部署前必须对比线上原版API路由，确保前端调用和后端返回字段一致
- Render免费版buildCommand: `npm install && npm run build`，startCommand: `node server.js`
