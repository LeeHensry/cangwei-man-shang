A股智能决策辅助系统 - 产品架构文档

产品定位

基于多因子模型 + LLM辅助解读 + 贝叶斯持续优化的A股交易决策系统，输出可执行的买卖建议（关注/买入/卖出/减仓 + 价格 + 仓位 + 理由）。

双策略体系

策略A：价值投资长线（主策略，主人风格匹配）

  • 核心：好公司 + 好价格 + 催化剂确认
  • 持仓周期：月~年级别
  • 仓位管理：金字塔建仓，单只上限20%
  • 卖出：高估/基本面恶化/更优标的

策略B：短线机会发现（辅助，主流量化短线）

  • 核心：热点板块 + 资金推动 + 情绪共振 + 严格风控
  • 持仓周期：天~周级别
  • 仓位管理：单只5-10%，短线总仓位≤30%
  • 风控：-8%无条件止损，持仓不超过5个交易日

LLM调用策略：

  • 盘前（8:00-9:00）：批量处理昨夜公告、新闻、外盘分析
  • 盘后（15:30-16:30）：批量处理当日重要公告、龙虎榜解读
  • 盘中：仅监控大盘涨跌停、持仓股重大波动（阈值触发）

决策层设计

买入信号逻辑（价值长线）

买入信号 = 质量分≥70 AND 估值分≤30 AND (催化剂满足≥1项)

催化剂包括：
  1. 最近一季业绩超预期（增速加速）
  2. 北向资金连续5日净买入
  3. 行业政策利好（LLM评分≥4星）
  4. 技术面底部放量突破（成交量20日均量1.5倍+突破20日线）
  5. PE/PB创近5年新低后企稳

建仓节奏：
  - 首次建仓：30%仓位
  - 每下跌5%：加仓20%
  - 最多加仓3次，单只总仓位≤20%

买入信号逻辑（短线机会）

短线信号 = 板块热度≥70 AND 个股短线分≥75 AND 风控放行

板块热度评分：
  - 板块涨幅≥2%：25分
  - 板块内≥3只涨停：25分
  - 主力资金净流入板块前5：20分
  - 有消息/政策催化(LLM确认)：20分
  - 连续2日活跃(非一日游)：10分

风控条件：
  - 大盘未处于暴跌状态(沪深300跌幅<2%)
  - 短线总仓位<30%
  - 近期无连续亏损冷静期

卖出信号逻辑

策略卖出条件操作
价值长线估值分≥85（高估）减仓50%
价值长线估值分≥95 或 PE创历史新高清仓
价值长线基本面恶化（质量分降至50以下）评估后清仓
价值长线发现更优标的（评分更高+估值更低）换仓
短线止损线（买入价-8%）无条件清仓
短线跌破5日线减仓50%
短线冲高放量滞涨/板块退潮清仓
短线持仓超过5个交易日强制评估，弱则清

仓位管理模块

总仓位动态调整（基于沪深300估值分位）：
  - 极度低估（PE分位<20%）：总仓位80-100%
  - 低估（20-40%）：总仓位60-80%
  - 合理（40-60%）：总仓位40-60%
  - 偏高（60-80%）：总仓位20-40%
  - 高估（>80%）：总仓位0-20%

仓位分配：
  - 长线仓位占比：70-90%（根据估值调整）
  - 短线仓位占比：10-30%（行情好时增加）
  - 现金：始终保留≥10%应对极端机会

风控引擎（硬约束，凌驾所有信号）

全局风控规则：
├── 单只股票仓位上限：长线20%，短线10%
├── 短线总仓位上限：30%
├── 单日新开仓不超过3只
├── 短线止损：-8%无条件止损（自动提醒）
├── 长线止损：-20%触发基本面重评
├── 黑天鹅熔断：大盘跌幅>3%时暂停新开仓
├── 连续亏损保护：连续3笔短线止损→暂停短线1周
├── 持仓集中度警告：单一行业仓位>40%提醒分散
└── 个股黑天鹅预警：持仓股突发利空(LLM判定)→紧急提示

贝叶斯优化模块

核心思路

用贝叶斯推理持续更新各因子的权重和阈值，而非固定不变。

具体机制

1. 先验： 初始权重基于投资理论和经验设定（即上文的权重）

2. 观测： 每笔交易（建议买入后实际走势）作为观测数据

  • 买入后N日涨跌幅（长线N=60日，短线N=5日）
  • 信号触发时各因子的实际取值
  • 最大回撤（持有期间）

3. 后验更新：

  • 对每个因子计算其信号预测能力（IC值，信息系数）
  • 预测能力强的因子权重上调，弱的下调
  • 阈值（如估值分30、质量分70）也根据历史最优调整

4. 更新频率： 每月一次批量更新，避免过度反应短期噪声

5. 防过拟合：

  • 权重调整设上下限（每个因子权重不低于5%，不高于40%）
  • 用滚动窗口（近3年数据）而非全历史
  • 区分训练集/验证集

回测系统

  • 回测区间：默认近5年
  • 回测指标：
  • 年化收益率、累计收益率
  • 最大回撤、夏普比率、Calmar比率
  • 胜率、盈亏比
  • 对比基准：沪深300指数
  • 回测维度：
  • 分年度回测（看不同市场环境下的表现）
  • 分市场状态（牛市/熊市/震荡市）
  • 长短策略分别回测+组合回测

LLM辅助模块具体实现

技术方案

  • LLM接口：复用现有LLM Gateway
  • 处理流程：

1. AKShare拉取当日新闻/公告文本

2. 构建Prompt，要求结构化输出JSON

3. LLM返回结构化结果（情绪、影响标的、力度评分）

4. 结果存入DuckDB，作为情绪因子供评分引擎使用

Prompt示例结构

你是一位A股资深分析师，请分析以下政策/新闻对A股市场的影响：

新闻内容：{news_content}

请以JSON格式输出：
{
  "sentiment": "positive|negative|neutral",
  "impact_score": 1-5,
  "affected_sectors": ["板块名1", "板块名2"],
  "affected_stocks": [{"code": "代码", "impact": "正面/负面", "reason": "原因"}],
  "summary": "一句话总结影响"
}
